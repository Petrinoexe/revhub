# revhub v0.1.0

Первая версия: панель для сети «хаб + выходные», где выходные сами инициируют
туннель до хаба, а хаб раздаёт через них клиентский трафик.

## Что внутри

**Панель**
- вход по паролю (PBKDF2-HMAC-SHA256, подписанная cookie, лимит попыток);
  подписка `/sub/<token>` публичная — клиенты обновляют её сами;
- UI карточками, без сборки и внешних зависимостей.

**Клиенты**
- VLESS: `tcp` / `ws` / `xhttp`, security `tls` или `reality`;
- TLS: `acme` (домен), `acmeip` (сертификат Let's Encrypt на голый IP,
  профиль shortlived ~6 дней), `selfsigned` (IP + пин), `file` (свои файлы);
- UUID, срок, квота, привязка к инбаундам, подписка.

**Узлы и туннели**
- `wg`, `wg-reverse`, `vless`; трафик всегда `from → to`;
- добавление хоста по SSH (пароль или ключ): панель ставит ядро и wireguard,
  кладёт файлы, применяет и проверяет результат на узле;
- мониторинг раз в 20 с: живость по SSH-баннеру, задержка, возраст handshake WG;
- управление сначала по WG-туннелю, напрямую — только если туннель лёг.

**Маршрутизация**
- упорядоченные правила → `direct` / `block` / `tun:<имя>`, первый матч;
- dry-run с предупреждением о правилах, которые могут перехватить.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/Petrinoexe/revhub/master/install.sh | bash
```

Скрипт сам определит IP, спросит порт панели и TLS (домен / IP через
Let's Encrypt / самоподписанный / без TLS), затем склонирует репозиторий,
соберёт бинарь (Go поставит сам, если его нет) и запустит панель пустой —
без инбаундов и клиентов. В конце печатает адрес входа, логин и пароль.

## Что пока не сделано

- один админ, без ролей; отзыв сессии = смена пароля;
- ротация ключа хоста SSH из UI (TOFU: первый ключ запоминается);
- продление сертификата перезапускает xray (hot-reload нет);
- IP-сертификат Let's Encrypt требует постоянно свободный порт 80 на узле.
